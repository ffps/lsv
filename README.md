
# <p align="center"><img src="icon.png" /><br />LightSpeed Image Viewer</p>

**LightSpeed Image Viewer** — компактный и быстрый просмотрщик изображений для Windows.

Основная идея проекта — **минимальный размер, быстрый запуск и отсутствие лишних зависимостей**.

## Основные особенности

- Windows-only.
- Один исполняемый файл `lsv.exe`.
- Не требует установки.
- Не требует Qt, .NET или других сторонних runtime-библиотек.
- Использует нативные Windows API.
- Максимально быстрое открытие изображений.
- Полноэкранный режим при запуске.
- Навигация по изображениям текущего каталога.
- Автоматическое определение формата по содержимому файла.
- Сохранение настроек в реестре Windows.
- Размер готового EXE — менее **300 кБ**.

## Поддерживаемые форматы

- JPEG / JPG
- PNG
- WebP
- GIF
- SVG
- ICO

Для JPEG автоматически обрабатывается EXIF Orientation.

## GIF

Анимированные GIF поддерживаются с покадровым воспроизведением:

- автоматическое воспроизведение и зацикливание;
- отображение текущего кадра и общего количества кадров;
- ручная навигация останавливает воспроизведение;
- `Left` — предыдущий кадр;
- `Right` — следующий кадр;
- за начало и конец GIF переход не выполняется;
- корректная обработка смещений кадров и disposal method;
- копируется именно **текущий отображаемый кадр**.

Пример заголовка:

```text
GIF 10/33 frames
```

## Масштабирование

Поддерживаются:

- Auto Fit;
- масштаб `1:1`;
- увеличение и уменьшение;
- масштабирование относительно курсора;
- панорамирование увеличенного изображения.

Небольшие изображения при обычном открытии не увеличиваются автоматически. Явный Auto Fit может увеличить их до размера доступной области.

## Управление

### Клавиатура

| Клавиша | Действие |
|---|---|
| `Esc` | Выход |
| `PageUp` | Предыдущее изображение |
| `PageDown` | Следующее изображение |
| `Home` | Первое изображение |
| `End` | Последнее изображение |
| `Left` | Предыдущий кадр GIF |
| `Right` | Следующий кадр GIF |
| `Ctrl+Left` | Поворот на 90° против часовой стрелки |
| `Ctrl+Right` | Поворот на 90° по часовой стрелке |
| `Numpad /` | Масштаб `1:1` |
| `Numpad +` | Увеличить |
| `Numpad -` | Уменьшить |
| `Numpad *` | Auto Fit |
| `I` | Информация |
| `C` | Копировать файл |
| `M` | Переместить файл |
| `Ctrl+C` | Копировать изображение |
| `Ctrl+Insert` | Копировать изображение |
| `Alt+Enter` | Полноэкранный / оконный режим |

Для GIF `Left` и `Right` работают как управление кадрами, если `Ctrl` не нажат.

### Мышь

- **Левая кнопка + перетаскивание** — панорамирование.
- **Shift + левая кнопка + перетаскивание** — выделение области для копирования.
- **Средняя кнопка** — переключение полноэкранного/оконного режима.

## Буфер обмена

### Копирование всего изображения

Используются:

- `Ctrl+C`
- `Ctrl+Insert`
- пункт **Copy** контекстного меню.

Изображение копируется в исходном разрешении.

### Копирование фрагмента

1. Зажать `Shift`.
2. Нажать левую кнопку мыши.
3. Выделить прямоугольную область.
4. Отпустить кнопку.

Фрагмент копируется в исходном разрешении.

Для GIF копируется **текущий отображаемый кадр**, а не первый кадр.

Для совместимости с разными Windows-программами используются PNG, `CF_BITMAP`, `CF_DIBV5` и классический 24-битный `CF_DIB`.

## Операции с файлами

### Копирование

Клавиша `C`.

Выбирается каталог назначения. Если файл уже существует, программа спрашивает подтверждение перезаписи.

После успешного копирования выполняется переход к следующему изображению.

### Перемещение

Клавиша `M`.

После успешного перемещения программа:

- удаляет файл из списка текущего каталога;
- остаётся в исходном каталоге;
- переходит к следующему изображению.

Последний выбранный каталог сохраняется в реестре (`HKCU\Software\LightSpeed`).

## Информация об изображении

Клавиша `I` открывает информационное окно.

Показываются:

- полный путь;
- формат;
- размеры изображения;
- размер файла;
- позиция в списке.

Для GIF отображаются также текущий кадр и общее количество кадров.

## Полноэкранный и оконный режим

По умолчанию программа запускается в полноэкранном режиме.

Переключение:

```text
Alt+Enter
```

или средней кнопкой мыши.

В оконном режиме сохраняются положение, ширина и высота окна.

Настройки:

```text
HKCU\Software\LightSpeed
```

Основные параметры:

```text
Fullscreen
WindowLeft
WindowTop
WindowWidth
WindowHeight
FileOperationPath
```

## Работа с несколькими изображениями

При открытии файла программа формирует список поддерживаемых изображений в текущем каталоге.

Список сортируется без учёта регистра.

- `PageUp` / `PageDown` — соседний файл.
- `Home` — первый файл.
- `End` — последний файл.

Файл без стандартного расширения также может быть открыт, если его формат определяется по содержимому.

## Автоматическое определение формата

Распознаются сигнатуры:

- JPEG — `FF D8 FF`
- PNG — стандартная PNG-сигнатура
- WebP — `RIFF ... WEBP`
- GIF — `GIF87a` / `GIF89a`
- ICO — сигнатура ICO
- SVG — поиск элемента `<svg`

Поэтому расширение файла не является единственным источником информации о формате.

## Технологии

Проект использует:

- C++20
- Win32 API
- Windows Imaging Component (WIC)
- Direct2D
- Windows Imaging Codecs
- NanoSVG для SVG

WIC используется для JPEG, PNG, WebP, GIF и ICO.

SVG обрабатывается через NanoSVG.
